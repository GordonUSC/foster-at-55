Boot Up the Soundsystem

Know where everything lives and save your first preset.

  1. 0-3

    Volume low. Load Serum 2 on a MIDI track. Main menu, Init Preset. You should see "- Init -" with OSC A on. Set MAIN to about halfway.

  2. 3-8

    Click each tab once: OSC, MIX, FX, MATRIX, GLOBAL. Say out loud what each page does. Back on OSC, find SUB, OSC A/B/C, NOISE, FILTER 1/2, the ENV/LFO strip, MACROS, CLIP, ARP.

  3. 8-13

    Open the presets browser. Search "bass." Audition 10 presets and tweak macros while previewing. For your 3 favorites, click the MATRIX tab and look at what is modulating what.

  4. 13-15

    Init Preset again. Fill ARTIST "Foster," DESC "first save." Save as FB_E01_Boot_v1.

You've got it when you can name all five tabs and find your saved preset in the browser.

A/B against Boogie T, "Forest Fire." Just listen for the bass in the drop: is it one sound or many layers? Spotify

Stretch Hover over controls with tooltips on and learn 5 knob names you did not know.

Saw Is Law

Build a fat, raw oscillator stack.

  1. 0-3

    Init Preset. Hold a low C (C1 or C2). OSC A is a saw by default.

  2. 3-8

    Sweep WT POS slowly and hear the tone morph. Raise UNISON to 4, then turn up DETUNE a little and BLEND. Hear it widen.

  3. 8-13

    Turn on SUB and set it one octave below. Turn on OSC B, set OCT to -1 or +1, pick a different wavetable. Balance LEVEL knobs so nothing clips. Add a touch of NOISE.

  4. 13-15

    Save FB_E02_SawStack_v1.

You've got it when turning on SUB makes the low end heavier without making it muddy.

A/B against Mersiv, "Sunburst." Spotify

Stretch Set UNISON high on OSC B only and keep SUB mono-solid.

Save as FB_E02_SawStack_v1

Filter Feels

Shape tone with a filter and route sources into it.

  1. 0-3

    Load FB_E02. Enable FILTER 1. Click A and B so both oscillators run through it; leave S (sub) off so the sub stays clean.

  2. 3-8

    Sweep CUTOFF low to high. Raise RES carefully (volume down first). Click and drag directly in the filter display to move cutoff and resonance with the mouse.

  3. 8-13

    Use the arrows next to the filter name to audition 10 filter types. Note 2 that sound "vowel-like" or "talky." Add DRIVE and FAT.

  4. 13-15

    Save FB_E03_FilterFeels_v1 with your two favorite filter types in DESC.

You've got it when you can make the bass go from dark to bright with one knob.

A/B against Whyte Fang, "333." Spotify

Stretch Turn on FILTER 2 and try series vs parallel routing.

Save as FB_E03_FilterFeels_v1

Envelope Shapes

Control how a note starts and stops, and set up bass voicing.

  1. 0-3

    Load FB_E03. Click ENV 1. It controls volume.

  2. 3-8

    Make three shapes: a pluck (ATK 0, DEC short, SUS 0), a pad (ATK long, REL long), and a bass (ATK 0, SUS full, REL short).

  3. 8-13

    Click ENV 2. Grab its drag handle and drop it on FILTER 1 CUTOFF. Set depth by dragging the blue ring. Short DEC on ENV 2 gives a "yow" at the start of each note. In VOICING, turn on MONO and LEGATO and raise PORTA a little for slides.

  4. 13-15

    Save FB_E04_EnvBass_v1.

You've got it when overlapping notes slide into each other instead of retriggering.

A/B against Tape B, "Keep Em In Check." Spotify

Stretch Turn on BPM for ENV 2 so its decay locks to tempo.

Save as FB_E04_EnvBass_v1

First Wub

The wobble. LFO on filter cutoff, locked to tempo.

  1. 0-3

    Load FB_E04. DAW tempo 140 BPM (classic dubstep half-time feel). Pull FILTER 1 CUTOFF fairly low.

  2. 3-8

    Drag LFO 1 onto CUTOFF, drag the blue ring up for big depth. Make sure BPM is on. Set RATE to 1/4. Hold a note: wub wub wub.

  3. 8-13

    Set the LFO mode to RETRIG so every note starts the wub at the same place. Try RATE 1/8, 1/16, then click TRIP for triplets. Draw on the LFO graph: add points, make a sharp drop, make a "stair step."

  4. 13-15

    Save FB_E05_FirstWub_v1.

You've got it when the wobble stays perfectly in time with your DAW's metronome.

A/B against PEEKABOO, "All I Need Is Bass." Spotify

Stretch Try the LFO's ENVELOPE mode for a one-shot "yoi" per note.

Save as FB_E05_FirstWub_v1

Send the squad your call

Macro Mayhem

Put the performance moves on 8 knobs. Learn the MATRIX.

  1. 0-3

    Load FB_E05. Find MACROS.

  2. 3-8

    Drag Macro 1 onto LFO 1 RATE. Now turning Macro 1 speeds up or slows down the wub. Rename it "WUB SPEED" if your version lets you double-click the label.

  3. 8-13

    Drag Macro 2 onto FILTER 1 CUTOFF and onto DRIVE at the same time (two destinations, one knob). Open the MATRIX tab. Find your assignments, adjust depth with the slider, try a source curve, bypass one and hear the difference.

  4. 13-15

    Record yourself in the DAW riding Macro 1 and 2 for 8 bars. Save FB_E06_Macros_v1.

You've got it when two knobs give you a whole drop's worth of movement.

A/B against LEVEL UP, "That One Dubstep Song." Spotify

Stretch Modulate one macro with an LFO (macros can be destinations).

Save as FB_E06_Macros_v1

Warp Zone

Growl and aggression from the oscillator itself.

  1. 0-3

    Load FB_E06. On OSC A, open the WARP slot 1 menu.

  2. 3-8

    Audition the warp modes. Serum 2 adds new warp modes including true FM and phase distortion, and you can stack two at once (Dual Warp). Turn the WARP knob slowly with each.

  3. 8-13

    Drag LFO 2 onto WT POS, synced at the same rate as LFO 1. Now the timbre and filter move together, which is where "talking" bass starts.

  4. 13-15

    Save FB_E07_Warp_v1.

You've got it when the bass sounds like it is saying something, not just opening and closing.

A/B against Ace Aura, "UMBRA." Spotify

Stretch Switch OSC C to Spectral mode and drop a vocal sample in. Volume down first.

Save as FB_E07_Warp_v1

Dirt Bus

Make it loud in feel, clean in the low end.

  1. 0-3

    Load FB_E07. Go to FX. Note the MAIN, BUS 1, BUS 2 tabs.

  2. 3-8

    Add Distortion. Raise drive with the volume down. Pull the module's MIX back if it is too fizzy.

  3. 8-13

    Add Compressor and set it to MULTIBAND. Add a Splitter L/H so lows stay clean while highs get dirty. Drag modules to reorder; bypass to compare.

  4. 13-15

    Visit the MIX tab and check levels. Save FB_E08_Dirt_v1.

You've got it when the bass is aggressive on top but the low end still hits clean on your speakers.

A/B against BRAINWAVEZ, "Bass Gang." Spotify

Stretch Put a Reverb on BUS 1 and send only the highs to it.

Save as FB_E08_Dirt_v1

Riddim Pattern

Use Serum's own sequencer to write the bass rhythm.

  1. 0-3

    Load FB_E08. Click CLIP to show the module, and activate it.

  2. 3-8

    Set the grid to 1/16. Draw a riddim-style rhythm: short notes with gaps, repeated. Set Key and Scale so wrong notes are impossible.

  3. 8-13

    Record macro moves into the clip (record automation into lanes). Try a second clip slot with a variation. Then try ARP briefly and compare.

  4. 13-15

    Save FB_E09_Riddim_v1.

You've got it when pressing one key plays a full bar of moving riddim bass.

A/B against Boogie T & Dodge & Fuski, "STEPPIN." Spotify

The Brainwavez Test

Build a full wub bass from Init in 15 minutes, no notes allowed.

  1. 0-3

    Init Preset. Tempo 140. MAIN halfway, limiter on master.

  2. 3-8

    OSC A saw plus unison, OSC B one octave off, SUB on. FILTER 1 on A and B. ENV 1 bass shape, MONO plus LEGATO.

  3. 8-13

    LFO 1 to CUTOFF (BPM, RETRIG). LFO 2 to WT POS. Macro 1 = wub speed. Macro 2 = cutoff plus drive. FX: Distortion, Multiband Compressor, Splitter L/H.

  4. 13-15

    Play an 8-bar drop riding the macros. Save FB_E10_Capstone_v1. Bounce it to audio.

You've got it when you can A/B your 8 bars against the reference and the energy, timing and movement feel in the same family (not identical).

A/B against BRAINWAVEZ, "Never Sleep." Backup: BRAINWAVEZ & Kuhlosul, "All You Got." Spotify Backup track

Stretch Send the bounce to the squad and say which knob did the most work.
